# smb-rta-lean

スーパーマリオブラザーズのスピードランの事実を、Lean 4 で確かめるプロジェクトです。

## 定理

| 定理 | 命題 | 状況 |
|---|---|---|
| [fast accel](Theorems/FastAccel-ja.md) | 小さいマリオが、陸のステージの最初のように地面で止まっていて、周りに何もないなら、本物のコントローラで、34 フレームで走りの最高速に達することができ、33 フレーム以下では達することができない。 | 34 フレームでできる: 定理。33 以下は無理: 緩めたモデルでの定理 |
| [TAS fast accel](Theorems/TasFastAccel-ja.md) | 同じ条件で、左右同時押しを許すと、32 フレームで走りの最高速に達することができ、31 フレーム以下では達することができない。 | 32 フレームでできる: 定理。30 以下は無理: 緩めたモデルでの定理。31 は無理: 全探索 |
| [最高速の上限](Theorems/TopSpeed-ja.md) | 動く床やツタ、土管などから離れていれば、マリオは 1 フレームに 2.5 ピクセルより多く右へ進むことはない。最高速で何にも触れずに走ると、ちょうど 2.5 ピクセル進む。 | 各処理の確認: 定理。書き換える処理がそれだけであること: 解析済みコードから |

各ページに、主張、Lean が証明していること、前提とその確かめ方、再現のしかたがあります。
1 つの定理は `Theorems/` の 3 つのファイルです: `Name.lean`（主張と、計算からそれが出ること）、
`Name.md`、`Name-ja.md`。

## 共通の部分

* [準備](docs/setup-ja.md) — `smbrta.json` を書き、ROM を置き、`python3 prove.py` を実行する（ROM は含まれません）。
* [エミュレータ](docs/emulator-ja.md) — Lean で書いたファミコンと、その確かめ方。
* [しくみ](docs/method-ja.md) — ゲームのコードを動かすモデル、たどり着ける状態の証明書、
  緩めたモデル、絞り込んだ正確な探索。

## 構成

```
Smbrta/      ライブラリ: ファミコン（Machine, Cpu）、TAS、名前の表、証明書、モデル
Theorems/    定理ごとに、主張 1 つとページ 1 つ（英語、日本語）
docs/        共通のページ
tools/       値の取り出し、テストデータ
Config.lean  リポジトリの外のファイルの場所（smbrta.json。見本は smbrta-tmpl.json）
Main.lean    コマンド（`smbrta`）
prove.py     smbrta.json から、定理の確認まで全部を実行する
```
