# かたまりの右端を越えたあと: どの高さへの着地も

ラウンド 34 で、[ボーナス部屋をつなぐ](c-5-RoomJoin-ja.md) のフィールド `offFloor` は次を言っていました。かたまりの右端を越えた最初のフレーム `t0` から入る 1 つ前のフレームまで、立って終わるフレームは床の高さか床の 1 段上で終わる。これがあったので、かたまりの右端を越えたあとのフレームの歩き（`offNext`、[かたまりの上から: 床までのフレーム](c-7-8-2-OffDrop-ja.md)）はほかの高さの立ちを外していました。このフィールドは本物の走りで成り立ちません。ラウンド 35 でなくなり、`offNext` は `anyNext` になりました。着地はどの高さでもかまいません。

## 本物の走りで成り立たない

`room-off-back FM2 400`（測っただけ）。部屋の最初の操作から: かたまりの上に立つまで、A を一定の間隔で押すでたらめな入力（`room-off-ways` の種類 2 と 6 と同じ）。そのあと `t0` まで右だけ（歩き）。そのあと左と A で戻る（種の 4 分の 1 では 6 フレームごとに A を新しく押す）。そのあと横の土管へ右、あとで左と右をかわるがわる押して、土管からまた歩いて降りるようにします。

| | |
|---|---|
| 種 | 400 |
| そのうちかたまりの上に立ち、その右端を越えたもの | 225 |
| そのうち横の土管に入ったもの | 225 |
| そのうち `t0` から床でも床の 1 段上でもない立ちがあるもの（`offFloor` に反する） | 29 |
| そういう立ち | 1,348、どれも 144 px |
| 入る 1 つ前のフレームが床の近くにない入り（`offNear` に反する） | 225 のうち 0 |
| `t0` からの、遅い落ちる力でジャンプの状態のフレーム | 6,532 |
| そのうち 1.5 px より多く動くもの（`offSlow` に反する） | 0 |

144 px は床の 2 段上で、横の土管の上に立っています。たとえばある走りは `t0 = C + 158` で、`t0 + 64` から 144 px に立ち、`t0 + 227` で入ります。ラウンド 34 の測定（`room-off-ways`、`t0` からの立ち 216）には 144 px のものはありませんでした。その入力は土管の上に登りませんでした。

## 証明したこと

```
RoomRun.next_E     :  C ≤ n  ∧  n + 1 < E  →  vE(n + 1) ∈ anyNext(vE(n))
RoomRun.land_bound :  かたまりの上からのジャンプの、t0 − 1 から n フレームあとの床より上への着地  →  t0 + aboveF ≤ E + 1
landS_spec         :  1 ≤ d  ∧  s ∈ landsAt(d)  ∧  d + i ≤ aboveF − 2  →  s から anyNext を i フレーム進んだ状態はどれも床の近くにない
```

* **入る前のどのフレームも `anyNext` の状態へ行く**（`next_E`）。フィールドは使いません。立ちは段の上なので（`stand_ok`）、踏み切りはその段のものです。空中では、フレームは `vstepR` か、どの高さでもその着地です。
* **降りること**（`descend_k`）。`t0 − 1` のかたまりの上からのジャンプの状態から `k` フレームあとには、ジャンプが床に届いたか、床より上のどこかの高さに着地したか（ラウンド 34 では床の 1 段上だけ）、まだジャンプの上にいます。
* **床より上への着地**（`land_bound`）。それは `t0 − 1` から `n` フレームあとで、`n ≥ max(above, 1)` です。`above` はかたまりの上より上にいたときからのフレームを数え（`OffDrop.above_after`）、着地は `t0 − 1` よりあとです。着地から `aboveF − 2 − max(above, 1)` フレームのあいだ、`anyNext` のどの状態も床の近くにありません（チェック `landS`）。それで、床の近くにある入る 1 つ前のフレーム（`offNear`）はもっとあとで、`t0 + aboveF ≤ E + 1` です。
* **探し方**（`OffDrop.visS`、`visS_spec`）。見た状態の集まりを持ちます。前に見た状態はもう追いません。それは小さい深さで見たので、もっと多くのフレーム追いました。`max(above, 1) = d` の状態の着地は層 `d` で探しに加わり（`landsAt d`）、それぞれ `aboveF − 2 − d` フレーム追います。チェック `standB`（`standFam` の立ちから、[かたまりの上の立ち](c-7-8-3-OffStand-ja.md)）は、あとから加わるもののない同じ探し方を使います。

## フィールド

なくなったもの:

* `offFloor`（`RoomRun` のフィールド）。

加えたもの: フィールドはありません。`RoomJoin.Checks` の ROM のチェック: `pipeAc` と `pipeBc` はなくなり、数 `pipeA = 8`、`pipeB = 4` と事実 `pipe_sum` もなくなりました。新しいチェック `landC`（`landS`）が代わりです。`standB` は今は `anyNext` を探します。

## 測ったこと

`room-off-stand`: かたまりの上からのジャンプ（7,069 の状態、そのうち床の高さより上で落ちているもの 6,049）の着地を、高さごとに。

| 着地の高さ | 状態 | 着地 | `max(above, 1)` の最小 | チェックするフレーム | 床の近くになる最初のフレーム |
|---|---|---|---|---|---|
| 32 px | 38 | 24 | 1 | 10 | 11 |
| 48、64、80、96、112、128 px | それぞれ 401 から 878 | それぞれ 182 から 280 | 1 | 10 | 13 までなし |
| 144 px | 768 | 174 | 4 | 7 | 12 |
| 160 px | 764 | 172 | 8 | 3 | 8 |

| チェック | 結果 | 時間（ネイティブ） |
|---|---|---|
| `landS` | 真 | 8.3 秒 |
| `standB`（2,048 の立ち、12 フレーム、どの高さの着地も） | 真 | 7.9 秒（見た状態の集まりなしでは 39.7 秒） |

ラウンド 34 では `pipeAc`、`pipeBc`、`standB` は 0.2 秒、1.0 秒、14.5 秒でした。

32 px の立ちからは、跳んで画面の上を越えられます。そこでは高さが床の値に回ります。垂直の状態は垂直のページを持たないからです。そういう状態は床の近くと数えます。これはチェックを厳しくするだけです。32 px の着地が 11 フレームで床の近くになるのはこのためです。チェックは 10 フレームでよいのです。
