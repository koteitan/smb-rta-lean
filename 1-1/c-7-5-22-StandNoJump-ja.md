# あとの立ち（そのあとジャンプなし）

[ボーナス部屋をつなぐ](c-5-RoomJoin-ja.md) のフィールド `stand_wall` は、`C + 51` より前で床のほかに立つのは `hstep` に従わないフレームの終わりだけ、と言います。ラウンド 22 から（[落下の最初の立ち](c-7-5-16-FirstStand-ja.md)）、状態 0 で終わる前のフレームがあるときだけ求めます。このラウンドでは、落下の終わり（`C + 34`）からは、その前のフレームからあと、ジャンプの入力のフレームがないときだけ求めます。そのフレームを使う定理は `wall_turn` だけで、そこにジャンプはありません。

## 命題

`vs(n)`、`st(n)` はフレーム `n` の終わりの縦の状態とプレイヤーの状態です。`inp(n + 1).jump`: フレーム `n + 1` で地上の A を新しく押す。`Follow(n)`: フレーム `n + 1` が `hstep` に従う。`OnFloor(s)`: `st = 0 ∧ y = 176`。

```
stand_wall（フィールド、狭めた）:
  C ≤ n,  n + 1 < C + 51,  (∃ j, C < j ≤ n ∧ st(j) = 0),
  (n + 1 < C + 34  ∨  ∃ j, C < j ≤ n ∧ st(j) = 0 ∧ ∀ l, j ≤ l ≤ n → ¬inp(l + 1).jump),
  st(n + 1) = 0,  ¬OnFloor(vs(n + 1))   →   ¬Follow(n)
  （前は 2 行目なしで同じもの）

RoomCore.stand_off（証明、同じように狭めた）:
  C ≤ n,  n + 1 < C + 51,
  (n + 1 < C + 34  ∨  ∃ j, C < j ≤ n ∧ st(j) = 0 ∧ ∀ l, j ≤ l ≤ n → ¬inp(l + 1).jump),
  st(n + 1) = 0,  ¬OnFloor(vs(n + 1))   →   ¬Follow(n)
```

## 証明のしかた

1. `stand_off_of` は前と同じく、状態 0 で終わる前のフレームがあるかで分けます。あればフィールドです。フィールドの新しい前提は `stand_off` の前提です。なければ、フレームは `C + 34` より前で（前提の 2 つ目の場合にはそのフレームがあります）、`stand_first` です。
2. `st_ne` も同じ前提を受けとります。`fall_air`、`stand_gap`、`wall_turn` の最初の立ち、`C + 34` より前のフレームは 1 つ目の場合を使います。
3. `wall_turn` は 2 つ目の場合を、壁での立ち `i` のあとから `i + k` までのフレームで使います。そこでもう一度立たないことを示します。`i` からジャンプがないので最初の力で落ち、`k` フレームのあいだ床にいません（`hnoj`）。ジャンプがないことは、前のフレームでの `hnoj`（`ih`、空中のフレームでは `hnoj` そのもの）からです。

## これが大事なわけ

このラウンドの前は、フィールドは床から跳んだあとの立ちも求めていました。たとえば `C + 51` より前にブロックの上に着くことです。そのフレームで横で止まらなければ、その着地は `hstep` に従い、フィールドは偽になります。測った走りでは、そこで立つのはフレーム 51 からです（TAS はブロックの上でフレーム 52 から 54、自分の走り 1 本がブロックの左側でフレーム 51。[落下の最初の立ち](c-7-5-16-FirstStand-ja.md)）。フィールドの範囲の 1 フレーム先です。状態 0 のフレームからジャンプがなければ、ブロックの上には行けません。ブロックの左側は、床から `h` 段の壁です。

## 測ったこと

`room-stand-first FM2 300`（このラウンド、TAS と自分の走り 2,100 本、126,060 フレーム）: フレーム 51 より前で床のほかに立つのは 49 回で、すべて落下の最初の立ちで、フレーム 18 から 30 です。状態 0 で終わる前のフレームのあとのものはありません。なので前のフィールドにも狭めたフィールドにも、測ったフレームはありません。

## 残ること

`C + 34` から `C + 50` までで、状態 0 のフレームのあとジャンプなしの立ちと、`C + 34` より前で前の立ちのあとの立ちでのフィールド。証明には、その立ちの移動の終わりで `WallQ` の条件が要ります（床のほかで立って始まるフレームのあとの縦のページは追っていません）。そして移動の終わりの速さと `hstep` のつながりが要ります（壁での速さ 0 の 1 px の押しもどし: `Follow` なら終わりは `P(n)` なので、移動の終わりの速さは −16 になるはず。止めるフレームのモデル `TopSpeed.Frame` は、そこの速さを上からしか押さえません）。
