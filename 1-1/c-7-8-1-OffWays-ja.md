# かたまりからの降り方: 測ったこと

[ボーナス部屋をつなぐ](c-5-RoomJoin-ja.md) のフィールド `way` は、走りがフレーム `t0`（かたまりの右端を越える最初のフレーム）でどうやってかたまりの右端を越えるかを言います: 1 回のジャンプでかたまりを越える（`Over`、項目 1-1-c-7-9）か、かたまりに乗って降りる（`Approach` と `Off`、項目 1-1-c-7-7 と 1-1-c-7-8）か。`Off` には 2 つの場合があります: かたまりの上からのジャンプ（`Off.jump`: 踏み切りのフレーム `T + 1`、かたまりの高さからのジャンプでフレーム `F ≤ E` に床に着く）と、歩いて降りる（`Off.step`: フレーム `t0` でかたまりの端を歩いて越え、`F ≤ E` までに床へ落ちる）。このラウンドでは測っただけで、フィールドは変えていません。

`Over` は起こりません: `RoomJoin.no_landing` がチェックとともにそれから `False` を証明します（床からも、かたまりの横からも、1 回のジャンプでかたまり全体を越えることはない）。なので本物の走りではフィールド `way` は `onto` です。

## 測ったこと

`room-off-check FM2 300`（測っただけ）: TAS と、部屋の最初の操作からの自分の走り 1,800 本（右へ行く 6 種類の入力。B と、でたらめな時のジャンプつき）。どれも横の土管に入るまでか 400 フレームまで。入る前にかたまりの右端を越えた走りでは、`t0` より前で立って終わる最後のフレームが降り方を決めます: かたまりの上で、フレーム `t0 − 1` もそこに立っている（歩いて降りる）、それより前にかたまりの上（そこからのジャンプ）、床か別の高さ（かたまりを越えるジャンプ）。`F` は `t0` から床の上で終わる最初のフレーム、`E` は入るフレームです。

| | 走り |
|---|---|
| 走り | 1,801 |
| 入る前にかたまりの右端を越えた | 243 |
| そのうち、かたまりの上から歩いて降りる（`Off.step`） | 242 |
| そのうち、かたまりの上からのジャンプ（`Off.jump`。TAS） | 1 |
| そのうち、かたまりを越えるジャンプ（`Over`） | 0 |
| 横の土管に入った走り | 124 |
| そのうち、`t0 ≤ F ≤ E` のある `F` で床の上 | 124 |
| そのうち `F > E`（`Off` が成り立たない） | 0 |

最初の操作からのいちばん少ないフレーム: `t0` は `C + 99`、`F` は `C + 111`、`E` は `C + 111`。`t0` から `F` までは、かたまりの上からのジャンプのあとで 12 フレーム以上、歩いて降りたあとで 17 フレーム以上です。TAS では、かたまりの上に最後に立つのは `C + 78`、右端を越えるのは `C + 99`、床に着くのは入るフレーム `C + 111` です。

## 残ること（証明していない）

- `Off`（項目 1-1-c-7-8）と、`way` のどちらの場合かはフィールドのままです。証明には、`t0` のあとの縦の状態を部屋の歩き（ジャンプからは `InRoom.air`、立って始まるフレームは `InRoom.stand`）で床までたどり、かたまりの上からの踏み切りを `VertJump.jumpOff`（`InRoom.jump`）に結ぶことが要ります。
  ラウンド 34 でこれをしました（[かたまりの上から: 床までのフレーム](c-7-8-2-OffDrop-ja.md)）。`Off` はなくなり、代わりに 1 フレームについての 5 つのフィールドを求めます。
- `Over`（項目 1-1-c-7-9）は、`way` が与えられれば起こらないことが証明されています（`no_landing`）。本物の走りが `way` の 2 つの場合のどちらかであることがフィールドです。
