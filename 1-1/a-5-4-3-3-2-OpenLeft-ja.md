# 出だしの左への上限

**主張.** [出だし](a-3-Opening-ja.md) のモデルで、1-1 の最初から、31 フレームのあいだにどの入力も `P(m₀)` より左へは行けません。`P(m₀)` は操作のときの位置（40 px）です。
なので最初の 31 フレームのどの終わりでも、位置は 0 以上で、そこで位置が 0 の下へ回り込むことはありません。

単位は 1/256 px です。`P(m₀) = 10240` です。`dist(u)` はモデルの状態 `u` が最初から動いた距離です（左は負）。モデルは [出だし](a-3-Opening-ja.md) のものです。
横のフレーム `hstep` と、A を 1 フレーム押したときと押し続けたときの長さのあいだのジャンプです。

```
leftCheck(T, n)     :  最初から n フレームの探索。もう −T を越えられない状態は捨てる
low_of_check        :  leftCheck(T, n) = true   →   ∀ k ≤ n,  Reach(start, k, u)  →  −T ≤ dist(u)
open_left （非公開）:  ∀ k < 32,  Reach(start, k, u)  →  −P(m₀) ≤ dist(u)        かつ        P(m₀) + 9744 < 2²⁴
```

Lean: `Theorems/OpenLeft.lean`（`keepL`、`leftCheck`、`reach_ge`、`low_of_check`。計算を使わずに証明）、非公開の `Proof/OpenFrames.lean` の `open_left`（探索を
`native_decide` で）。

## しくみ

[出だし](a-3-Opening-ja.md) の探索を左へ向けたものです。ポテンシャル `Φ` は速さを両側から抑えます: `V = 256·v + f` として `|V| ≤ Φ` です（`Potential.step_J`）。
左へ動くとき、速さのバイトは `V` の上限より 1 小さくなることがあります。なので `Φ ≤ p` から 1 フレームあとの速さは `p' = nxt(p)` として `−(p'/256 + 1)` 以上です。
`Φ ≤ p` からの `n` フレームで左へ動けるのは多くても

```
dl(p, n)  =  Σ_{j=1..n}  16·(p_j / 256 + 1),        p_0 = p,  p_j = nxt(p_{j−1})
```

です（`SurfaceFrames.dl`。パート e と同じ上限。`reach_ge`）。探索は、残り `r` フレームの状態 `x` が領域の中にあって `dist(x) − dl(pOf(x), r) ≥ −T` のとき捨てます
（`keepL`）。残したどの状態でも `−T ≤ dist` を確かめます。

## 数

プログラム `open-left-check N T`:

| フレーム | `T` | 結果 | 時間 |
|---|---|---|---|
| 31 | 10240 | true | 1.3 秒 |
| 31 | 10100 | true | 1.2 秒 |
| 31 | 9600 | false | 1.6 秒 |
| 32 | 10240 | false | 1.8 秒 |
| 32 | 10500 | true | 1.8 秒 |

なので 32 フレームでは、モデルは左へ 10241 から 10500 のあいだまで行けます。フレーム 32 の終わりでは、モデルは位置 0 より左にいることがあります。本物の機械では
画面の左端が止めます。スクロールの処理が位置を端に書き戻します。モデルには端がありません。試した本物の走りでいちばん左へ行くもの（最初のフレームで A と B と左、
そのあと B と左）は、数えるフレーム 33 を `P = 320` で始めます。端には触りません。

`dl` だけではここで弱すぎます: `dl(Φ(start), 32) = 11328 > 10240` です。探索が要ります。

## 使い道

[本物のフレームでの出だし](a-5-4-OpenFrames-ja.md) が使います。最初の 31 フレームのどの終わりでも位置はちょうどです（回り込まない）。フレーム 32 の終わりには
条件が残ります（`Real.page`: 数えるフレーム 33 が始まるとき、ページは 255 でない）。

## 前提（Lean では証明していない）

新しいものはありません。モデルは [出だし](a-3-Opening-ja.md) のものです。

**再現.**
```
.lake/build/bin/smbrta open-left-check 31 10240     # true
.lake/build/bin/smbrta open-left-check 32 10240     # false
```
