# 触った終わりから城までの行（測っただけ）

**主張.** これは測ったことで、証明ではありません。動画の旗竿に触ったフレームの終わりの機械から、抽象状態の行は、どの入力でも（Start も含めて）城に入るところまで届きます。始めに 350 バイトを知らなくても届きます。でも、行は Start なしで 10 s、Start ありで 295 s かかります。始めの状態は、まだ動画の機械の 1698 バイトを知っています。なので `Route.Run` のフィールド `flag.entry`、`flag.task_E`、`flag.y_E` は残ります。証明に要る 4 つのことを最後に書きます。

## ゲームがすること

* 触るフレームは `FlagpoleCollision` を走らせます。ルーチンは 4（すべり降り）になります。マリオはのぼる状態になり、速さは 0 になり、`x` は旗竿の列から決まります。点数の番号は高さから決まります。音楽を止めるように頼み、スクロールを止めます。
* ルーチン 4（`FlagpoleSlide`）はマリオを下ろします。`FlagpoleRoutine` は旗を下ろします。旗かマリオが十分低くなると、点数を与えてルーチン 5 にします。動画のように旗竿の低いところでつかむと、触るフレームのうちにルーチン 5 になります。
* ルーチン 5（`PlayerEndLevel`）はマリオを右へ歩かせます。旗竿を離れると、面の終わりの音楽を頼みます。マリオの右側が城の壁に当たると、壁が当たりのビットのビット 0 を消し、ルーチンは星の旗の処理を 1 にします。同じフレームのあとで星の旗のルーチンが走り、処理を 2 にします。なので城の旗が立つ最初のフレームは処理 2 で終わります。
* ルーチン 4 と 5 ではゲームのタイマーは進みません。ポーズで終わるフレームはゲームを走らせません。

## 行

`row(j)` は、触った終わりから、ポーズでなく終わるフレームを `j` 個過ぎたあとの、フレームの始めの状態です。これは `pole` がフレームを数えるやり方です。ポーズで終わるフレームは同じ行に戻ります。

```
触った終わり               ∈  row(0)
S ∈ row(j)、どの入力 i:    frame(S, i) がポーズで終わる      →  frame(S, i) ∈ row(j)
                           frame(S, i) がポーズでなく終わる  →  frame(S, i) ∈ row(j + 1)、または城の旗が立つ
```

各状態のフレームを 1 つずつ、アイドルループからフレームの終わりまで、パッドを知らないまま探します。行の中では、ドットが同じで、次のバイトの知っている値が同じ終わりをまとめます。ポーズの状態、画面のバッファの位置と最初のバイト、音楽のキューとバッファ、音楽のポインタ、ポーズの音のバイトです。探すときもこれらのバイトを分けておきます。音楽のキューとポーズの音のバイトを読むときは、値ごとに分けます（`Env.splits`）。音楽の四角波 1 の位置は、[城に入ったあとの星の旗の規則](g-2-1-FlagRule-ja.md)と同じように分けます。

## 測ったこと

始めは、動画の触ったフレームの終わりの機械です。フレーム 1093（`b₂ + 240`）が始まるときの機械です。城の旗は、フレーム 1218 のあと、フレーム 1219（`b₂ + 366`）が始まるときに立っています。なので、ポーズでなく終わるフレームを 126 個過ぎたあとです。どれも機械がほぼ空いているときに 1 回ずつ測りました。

```
始めに知らないバイト              Start   城の旗       行の状態の数            探した数   歩数      時間
なし                              なし    行 126       2                       251        1.6 M     3.6 s
350                               なし    行 126       4                       537        4.1 M     10.4 s
なし                              あり    行 126       36、行 66 から 108      11455      55.9 M    119 s
350                               あり    行 126       54、行 66 から 162      16553      123 M     295 s
350、音楽の位置、効果音           あり    最初の行が 10 分で終わらない
```

350 バイトは、一時的なバイト、スタックの上のほう、スプライト、乱数、フレームカウンタ、位相とほかの 4 つの数えるタイマー、パッドのバイト、ゲームのタイマーの数字、スコアとコインです。

面の終わりの音楽は行 66 で始まります。そこからは、ポーズが音楽を遅らせることがあり、行の状態は音楽の位置が違います。なので行 66 から行が大きくなります。

## 証明に要ること

1. **触った終わりの条件.** [城に入ったときの条件を広げる](g-2-2-1-FlagWide-ja.md)の 31 の本物の走りでは、触った終わりの機械は、どれかの走りで動画のものと 289 バイト違います。触った高さ、マリオの縦の状態、画面、音、ほかのスロットです。動画とポーズのある 12 の走りでは 26 バイト違います。音、ポーズ、乱数です。上の行は 1698 バイトを知っています。ほかの高さで触る走りでも正しい条件にするには、もっと多くのバイトを知らない行が要ります。それは測っていません。
2. **ポーズ.** ポーズは行の状態の数を増やします（全部知っているとき 2 → 108）。時間は 3.6 s から 119 s になります。音楽の位置を知らないと、各フレームが四角波 1 の位置を分け、最初の行が終わりません。
3. **`E + 1` の数.** `Good` は、タイマーの数字がある `t ≤ tmax` の数字であることを求めます。始めに数字を知らないなら、3 つの数字のバイトを各フレームで保つ歩きがさらに要ります。星の旗の確認の保つ歩きと同じです。どれもおもな歩きと同じ長さです。
4. **`E` がどのフレームか.** `flag` は `seq(E + 1)` を読みます。`LagUp` から `seq(E + 1) = pole.seq(c)` です（`Run.castle_join`）。`pole.atCastle` はそこで城の旗が立つと言います。でも `c` が城の旗の立つ最初の数えるフレームだとは、どこにも書いていません。`task_E` は処理 2 のフレームでしか成り立ちません。行からは、触った終わりのあとで城の旗が立つ最初のフレームは処理 2 で終わるとわかります。これを使うには、`flag` に、`E` をそこに置く 1 フレームごとの条件が要ります。たとえば次です。

```
∀ n,  触った終わり ≤ n ≤ E  →  ¬castle(seq n)、        castle(seq(E + 1))
```

この条件はいま `Run.FirstCastle`（`b₂` から）で、`castle(seq(E + 1))` は `Run.castle_E` です（[城をつなぐ](0-5-2-1-CastleJoin-ja.md)）。触るフレームの終わりまでは証明しました（`Run.noCastle_up`）。これがあれば、`E` は `b₂` から城の旗で終わる最初のフレームで（`Run.E_first`）、`LagUp` もあれば `c` は城の旗のある最初の数えるフレームです（`Run.c_first`）。触った終わりから `E` までのフレームは仮定のままです（`Run.firstCastle_of` の `hA`）。上の行がそれを与えるはずです。

## 証明していないこと

* このページのことは何も証明していません。`flag.entry`、`flag.task_E`、`flag.y_E` は仮定のままです（1-1-g-2-2）。
* 行は動画の機械から始まります。動画はプログラムが始めの状態を作るのに使うだけです。Lean のファイルには動画の何も入っていません。
* 触るフレームのあとの位相の規則（`Run.lagUp_of` の `hA`）と、触ったあとの長さ（パート f の `flagAny`、`flagTight`、`other`）も、このような行から読めるかもしれません。それは測っていません。

## ファイル

プログラムだけです。`Main.lean` の `touchRowsPaused`、`touchRowsProbe`（`touch-rows-check`）、`touchRunOf`、`touchEndProbe`（`touch-end-check`）。

```
.lake/build/bin/smbrta touch-rows-check FM2 ns-pad     # 全部のバイトを知る、Start なし
.lake/build/bin/smbrta touch-rows-check FM2 ns-real0   # 350 バイトを知らない、Start なし
.lake/build/bin/smbrta touch-rows-check FM2 pad        # 全部のバイトを知る、どの入力でも
.lake/build/bin/smbrta touch-rows-check FM2 real0      # 350 バイトを知らない、どの入力でも
.lake/build/bin/smbrta touch-rows-check FM2 real       # 音楽の位置と効果音も知らない（終わらない）
.lake/build/bin/smbrta touch-end-check FM2 [N]         # 本物の走りでの触った終わりと城に入るとき
```
