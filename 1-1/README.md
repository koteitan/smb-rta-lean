# 1-1

Theorems toward a lower bound on the frame 1-2 starts. The work in progress by part is in [The 1-1 route](../docs/route-1-1.md).

A label is `<world>-<stage>-<part>-<number>[-<sub>]`. `0-0` is what several stages share, and part `0` is what no single part owns.

## Part 0 (the whole stage)

Joins all the parts into a lower bound on the frame 1-2 starts.

| label | theorem | statement | status |
|---|---|---|---|
| 1-1-0-1 | [The whole of 1-1](0-1-Route.md) | If a run satisfies every assumption of `Run`, 1-2 does not start before frame 1748. | a Lean theorem joining the parts; the assumptions are listed as the fields of `Run`, not proved for every run |
| 1-1-0-5-3 | [From Start on the title to control](0-5-3-TitleStart.md) | If the machine after the press of Start on the title meets one condition, then with any input up to control, Start included, frame 0 begins with the timer at 401, the phase 2 and no hurry-up music, and the speed at control is 0. | a Lean theorem from a set of abstract states closed under one frame with any input, checked by `native_decide` (about 4 s natively); the condition holds on 339 real runs, 117 with pauses |
| 1-1-0-6-4 | [Runs with the hurry-up music](0-6-4-HurryMusic.md) | In a run with the hurry-up music, 1-2 does not start before frame 1748. | a Lean theorem from the timer's rule and walks of whole frames in control up to the first frame that starts the music (hypotheses `start` on the first of them, `ctl`, `clean`, `below`), checked on 108 runs (7,559 frames) |
| 1-1-0-6-4-2-1 | [The frame that starts the hurry-up music](0-6-4-2-1-HurryFrame.md) | A whole frame that starts in control or in the entrance without the hurry-up music, if each of its instructions meets one condition, ends without it or with the timer at 100 or less, and if it ends with control, it ends with the music queued or at the start of a frame in control. | one whole frame by the abstract machine; the check by `native_decide` (about 4 s); checked on the 108 real frames that start the music. Not proved: `start` of the first frame in control, `clean` |
