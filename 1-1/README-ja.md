# 1-1

1-2 が始まるフレームの下界に向けた定理です。パートごとの途中経過は[1-1 の道筋](../docs/route-1-1-ja.md)にあります。

記号は `<ワールド>-<ステージ>-<パート>-<番号>[-<サブ番号>]` です。`0-0` は複数のステージに共通のもの、パート `0` は特定のパートでないものです。
