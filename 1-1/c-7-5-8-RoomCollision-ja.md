# 当たり判定の座標・タイル・復帰

`RoomCollision.routine` は、プレイヤーの `BlockBufferCollision` の呼び出し全体を証明します。前提は、ROM の検査、`Good`、入口のプログラムカウンタ、X がプレイヤーの番号であることです。ずれの添字 Y、最初の A、フラグ、スタックポインタ、位置のバイトは任意です。TAS の状態には固定していません。

R を入口、i をずれの添字、T をタイルの読みの機械、Q を復帰した機械とします。ずれ、行のマスク、画面上部の引く量、最後の座標のマスクは ROM から読みます。

```
a = selector(page(R), x(R), 横のずれ(i))
r = ((y(R) + 縦のずれ(i)) & 行のマスク) - 画面上部の量
読み出し先 = バッファの始まり + (a / 16) * 半分の長さ + (a % 16) + r
```

r は行のバイトのずれで、バイトの計算で求めます。`RoomAddress.encoded_eq_selector` が横の桁上がりをページにつなぎます。`actual_address` は、実際の間接読みの番地がこの式になることを証明します。`read_value` は、その値を T の現在の RAM のバイトにつなぎます。

T まで 93 命令以内、そのあと Q まで 25 命令以内で、次を証明します。

- Q の A と保存したタイルは、T で読んだバイトです。
- 保存した行は r です。
- 保存した座標は、最初の A が 0 なら入口の y、それ以外なら入口の x にマスクを掛けた値です。
- 復帰先は R の元の呼び出し元のスタックから決まり、SP は 2 進みます。
- 座標のバイトは T まで保たれます。各命令は `InFrameN` を満たし、既存のフレームの時間の補題で使えます。

`ReadAt` と `Returned` は、これらの結論を並べたものです。`Route.Run` の新しいフィールドではありません。対象はプレイヤーで、任意の敵の番号の呼び出しは含みません。

## 地図とフレーム全体

`returned_map` は、T での `RoomBlocks.Solid` と結果を合わせます。計算した番地がブロックバッファ内にあり、参照する地図のバイトがコインでなければ、Q がその地図のバイトを返します。任意の入口の高さでは地図の外を読むこともあるので、バッファ内であることを明示します。

`Run.roomBlocks` は、フレームの境目で地図との一致を与えます。既存の 1 フレームの証明は、その内部で命令ごとの一致も追いますが、このページでは、すべての読みの状態への公開された接続まで済んだとは言いません。その接続、各呼び出しでの移動後の位置、頭・足・横の添字の選択、返されたタイルから先の分岐をつなぐ必要があります。`land_at`、`stand_wall`、`wall` は残ります。フィールドの増減も、大きな探索の拡大もしていません。

part d は、パイプ近くの頭と横の読みに、同じ任意の添字の定理を使えます。part f は、`TileRead` の番地と値に使えます。どちらも、実際の呼び出しの入口と、そのあとの分岐との接続が必要です。

**ファイル:** `Theorems/RoomCollision.lean`、非公開の `Proof/RoomCollision.lean` と `room_collision_check`。[列のポインタの補題](c-7-5-7-RoomAddress-ja.md) の元の型は保っています。

## 実データでの検査

ROM の検査は真で、ネイティブで 2,617 ms でした。`room-floor-check FM2 60` は TAS と自作入力の 59,811 フレームを検査しました。プレイヤーの呼び出し・読み・復帰はそれぞれ 410,104 回です。入口の `Good`、入口の位置から計算した番地、行、座標の保存、返り値と作業用の値、命令数の失敗はすべて 0 回で、未完了の呼び出しも 0 回でした。終了コードは 0 です。

`room-jump-check FM2 100` は 1,101 走り・88,111 フレーム、`room-stand-check FM2 100` は 701 走り・56,111 フレームで、ともに `bad: 0`、終了コード 0 でした。これらは実行例の検査で、着地と壁の残る前提を証明するものではありません。
