# かたまりの上から: 床までのフレーム

[ボーナス部屋をつなぐ](c-5-RoomJoin-ja.md) のフィールド `Off`（項目 1-1-c-7-8）は、かたまりの右端を越えた最初のフレーム `t0` のあと、かたまりの上から床までどう行くかを言っていました。かたまりの上からのジャンプで、その弧が入るフレーム `E` までに床に届くか、歩いて降りるかです。その弧、フレーム `F`、`t0` のあとのフレームは機械から読んでいませんでした。`read_vs` は垂直の状態を `t0` までしか読みません。ラウンド 34 から `Off` はなくなりました。ルートが `Off` から取っていたことを、`RoomRun.off_gap_of` が `t0` のあとの本物のフレームで証明します。代わりに 5 つのフィールドがあり、どれも 1 フレームか 1 状態についてです。

## 証明したこと

`vE(n)` は部屋のフレーム `n` の終わりの垂直の状態で、機械から読みます（`RoomRun.vE`）。高さ `y`、状態 `st`（0 立つ、1 ジャンプ、2 落ちる）、垂直の速さとその端数、2 つの力 `vf`、`vfd`、ジャンプの起点です。`y_top` はかたまりの上に立つ高さで、床の高さ `y_floor` より 48 px 上です。

```
RoomRun.off_gap_of :  t0 < E  ∧  t0 + aboveF ≤ E + 1          (aboveF = 13: 入るのは t0 から 12 フレーム以上あと)
RoomCore.off_gap   :  同じこと。way のフィールド Off の代わりの RoomCore の事実
entry_ge           :  C + goalF + aboveF ≤ E                  (past_late: C + goalF < t0 から。変わらず E ≥ C + 111)
```

部屋のフレームの歩きは、`t0` までではなく、入る 1 つ前のフレームまで成り立ちます。それで `t0` のあとの垂直のバイトを本物のフレームでたどります。

* 空中のフレームは前の状態の `vstepR` か、その着地です（`RoomRun.air_E`、`InRoom.air` から）。
* 立って始まりジャンプのないフレームは、`StandNext` の許すように終わります（`stand_E`、`InRoom.stand` から）。
* ジャンプのあるフレームは、その高さからの踏み切りで終わります（`jump_E`、`InRoom.jump` から）。

証明は、`t0` より前で立って終わる最後のフレーム `T` で 2 つに分かれます（フィールド `offTop` が `T` をかたまりの上に置きます）。

* `T + 1 < t0`: フレーム `T + 1` で踏み切ります。ジャンプがなければ高さ `y_top` のままですが、このフレームはかたまりの上より上で終わります。踏み切りは、かたまりの上からのジャンプの最初の状態です（`OffDrop.offAt`、チェック `offT`）。`t0 − 1` まで、本物のフレームはそのジャンプの状態です。空中で終わるので着地せず、`vstepR` はこのジャンプのどの状態でも `vstep` です（かたまりの上からの `VertAir.bridgeAll`、チェック `bridgeB`）。かたまりの上より上にいる `t0 − 1` から、`descend_k` がジャンプを 3 つの終わりのどれかまでたどります。
  * ジャンプが `F ≤ E` のフレームで床の高さに届く。
  * 床の 1 段上、横の土管の上に着地する（ラウンド 35 からは床より上のどの高さでも、`land_bound`）。
  * `E − 1` でまだジャンプの上にいて、もう 1 フレームで床に届く（フィールド `offNear`。ラウンド 36 から `RoomRun.offNear_of`、[入るフレーム](c-7-8-5-EntryVert-ja.md)）。

  そして:
  * 速いジャンプは、`t0 − 1` から `aboveF` フレーム以上あとに床に届きます（チェック `drop`、`dropOk`。かたまりの上より上にいたときからのフレームを数えます。`OffDrop.above_after`）。
  * 遅いジャンプは `t0 − 1` から `aboveS = 12` フレーム以上あとです。
  * 床の 1 段上への着地は `t0 − 1` から `pipeA = 8` フレーム以上あとです（`pipeAOk`）。そこから `pipeB = 4` フレームのあいだ、床の近くの状態はありません（`pipeLands` での `offB`）。そして `aboveF ≤ pipeA + pipeB + 1` です。ラウンド 35 からは、床より上のどの高さへの着地も `t0 − 1` から `n ≥ max(above, 1)` フレームあとで、そこから `aboveF − 2 − max(above, 1)` フレームのあいだ床の近くの状態はありません（チェック `landS`、[かたまりの右端を越えたあと: どの高さへの着地も](c-7-8-4-OffLand-ja.md)）。
  * 遅いジャンプがちょうど `t0 − 1` から `aboveS` フレームあとに入るなら、`t0 − 1` から `E − 1` までのどのフレームもその遅いジャンプの状態です。ジャンプの状態で、遅い踏み切りの落ちる力です（`OffDrop.slowArcs`、チェック `slowB`）。するとフィールド `offSlow` で 1 フレームに `A − 1` 十六分の一ピクセル（1.5 px）しか動かず（ラウンド 37 からこれは証明です。`slow_run`、移動の終わりのあとはフィールド `offCollide`: [`t0` のあとの空中の速さの上限](c-7-8-6-AirMove-ja.md)）、`P(E) ≤ P(t0 − 1) + 16·(A − 1)·aboveS < goal + 16·(A − 1)·aboveS ≤ mouth ≤ P(E)` です（`slow_mouth`、`mouth`、`first`）。これはありえません。
* `T + 1 = t0`: フレーム `t0 − 1` はかたまりの上に立って終わります。ラウンド 34 まではフィールド `offStand` でその状態が `standFam` の 1 つでした。ラウンド 35 からは、ジャンプの力を落ちる力に、起点をかたまりの上に置いたその状態が `standFam` の 1 つで、立つときと落ちるときはその 2 つのバイトを読みません（`SimV`、[かたまりの上の立ち: 落ちるときに読まないバイト](c-7-8-3-OffStand-ja.md)）。チェック `standB` はその状態から `offNext` を `aboveF − 1` フレーム進み、床の近くの状態はありません。フレーム `t0` は歩いて降りるか、跳ぶか、立ったままです（ラウンド 34 までは `offFloor` で立つのは床か床の 1 段上だけ。ラウンド 35 からはどの高さでも）。それで入る 1 つ前のフレームは `t0 − 1` から 12 フレームより先です（`offB_path_sim`、`offB_gap_sim`）。

`offNext` は、かたまりの右端を越えたあとの、着地を床か床の 1 段上だけにした `anyNext` でした。空中では A ありとなしの `vstepR` と、その高さへのその着地。立っているときは、`noJumpNext` のうち空中かその高さに立つ状態と、その段からの踏み切りです。ラウンド 35 からは `offNext` は `anyNext` で、着地はどの高さでもかまいません。`near(s)`（`OffDrop.nearB`）は、`y_floor` に立つか、空中で A ありかなしの `vstepR` 1 フレームで `y_floor` 以下に落ちることです。

## フィールド

なくなったもの:

* `Off`（`way` の中）: かたまりからのジャンプか歩いて降りること、`F ≤ E` と `slowJ`。`Way.onto` は `Approach` だけを持ちます。`Off` からの `RoomCore.t0_le_E` と `t0_lt_E` はなくなり、`past_late` は `t0 < E` を `off_gap` から取ります。

加えたもの（`RoomRun` のフィールドで、どれも 1 フレームか 1 状態について）:

```
offTop   :  ∃ T,  C ≤ T < t0  ∧  st(vE T) = 0  ∧  y(vE T) = y_top  ∧  ∀ j ∈ (T, t0),  st(vE j) ≠ 0  ∧  y(vE j) < y_top
offFloor :  ∀ n ∈ [t0, E),  st(vE n) = 0  →  y(vE n) = y_floor  ∨  y(vE n) + 16 = y_floor          （本物の走りで成り立たない。ラウンド 35 でなくなった）
offNear  :  near(vE(E − 1))                                                         （ラウンド 36 で証明。なくなった）
offSlow  :  ∀ n ∈ [t0 − 1, E),  st(vE n) = 1  ∧  vfd(vE n) ∈ F_slow  →  P(n + 1) ≤ P(n) + 16·(A − 1)          （ラウンド 37 でなくなった。かわりに offCollide）
offStand :  st(vE(t0 − 1)) = 0  →  vf = vfd  ∧  vfd ∈ forces  ∧  origin ∈ {y_top, y_floor, y_floor − 16, y_floor − 32}        （ラウンド 35 でなくなった）
```

`offStand` はラウンド 35 でなくなりました（項目 1-1-c-7-8-3、[かたまりの上の立ち: 落ちるときに読まないバイト](c-7-8-3-OffStand-ja.md)）。`offFloor` は本物の走りで成り立ちません。`t0` から彼は横の土管の上、床の 2 段上に立ち、そのあと入れます。ラウンド 35 でなくなりました（項目 1-1-c-7-8-4、[かたまりの右端を越えたあと: どの高さへの着地も](c-7-8-4-OffLand-ja.md)）。`offNear` はラウンド 36 で証明しました（項目 1-1-c-7-8-5、[入るフレーム](c-7-8-5-EntryVert-ja.md)）。`offSlow` はラウンド 37 でなくなりました（項目 1-1-c-7-8-6、[`t0` のあとの空中の速さの上限](c-7-8-6-AirMove-ja.md)）。かわりに同じフレームについてフィールド `offCollide` があります。各フレームの移動の終わりのあとの位置です。だから `offTop` と `offCollide` が残ります。

**ラウンド 36: 残さなかった狭め。** 2 つのフィールドに前提 `E + 1 < t0 + aboveF`（`offTop`）と `E = t0 − 1 + aboveS`（`offSlow`）を足した形でも、背理法で `off_gap_of` は証明できました。しかし証明された事実と合わせると、その 2 つの形は合わせてちょうど `t0 + aboveF ≤ E + 1`、つまり `off_gap_of` の結論を言います。それは 1 つのフレームの事実ではなく、結果を仮定することになります。だからフィールドはラウンド 34 の形のままです。測った走りに `t0` から 12 フレームより早く入るものはありません（`room-off-back FM2 400`、`room-off-ways FM2 300`。`E − t0` の最小は 12 で、ムービーのもの）。

その立ちに垂直の速さがないことは証明しています（`RoomRun.stand_ok`）。入る前の部屋のどの立ちも、垂直の速さがなく段の上にあります。最初の操作で彼は落ちていて（チェック `startAir`）、着地には速さがなく、立って始まりジャンプのないフレームは高さと速さを保つか着地し（`StandNext`）、段からの踏み切りはどれも立ちません（`jumpAirCheck`、チェック `jumpAir`）。

`F_slow`（`OffDrop.slowF`）は、空中のしきい値より下でのかたまりの上からの踏み切りの落ちる力です。`forces` はすべての踏み切りの落ちる力です。`P(n)` はフレーム `n` の終わりの位置で、機械から読みます。

この 5 つは、どこでも `Off` より弱いわけではありません。`Off` はタイミングだけを求め、`t0` のあとのフレームは自由なデータでした。5 つは本物のフレームの事実を求め、タイミングはそこから証明します。

新しい ROM のチェック（非公開の `Proof/RoomJoin.lean` の `room_checks` で `native_decide`）: `bridgeB`、`offT`、`slowB`、`pipeAc`、`pipeBc`、`standB`、`startAir`、`jumpAir`（ラウンド 35 からは `pipeAc` と `pipeBc` の代わりに `landC`）。合わせて非公開のビルドが約 30 秒長くなります（`Proof.RoomJoin` は静かな機械で 145 秒、ほかの走りがあると 193 秒、前は 116 秒）。`standB` はネイティブで 15 秒から 28 秒です。新しい数: `pipeA = 8`、`pipeB = 4`。事実 `off_two : 2 ≤ aboveF` と `pipe_sum : aboveF ≤ pipeA + pipeB + 1` があります（ラウンド 35 で `pipeA`、`pipeB`、`pipe_sum` はなくなりました。`off_two` は残ります。チェック `keepA` と `offVfd` を足しました: [かたまりの上の立ち](c-7-8-3-OffStand-ja.md)）。

## 残ること（証明していない）

* 5 つの新しいフィールドのうち 3 つ。あとで証明する道:
  * `offTop`: かたまりの右の列。`t0 − 1` で左足はその上にあるので、その上の面か、それより上にいます。証明には、`t0` より前の立ちがどこにありうるかと、かたまりの上に降りずにかたまりの右端を越えるジャンプが起きないこと（`way` のフィールドからの `Over` について `no_landing` が示すように）も要ります。
  * `offFloor`: 本物の走りで成り立たず、ラウンド 35 でなくなりました（項目 1-1-c-7-8-4）。証明はどの高さへの着地も許します。
  * `offNear`: ラウンド 36 で証明しました（項目 1-1-c-7-8-5、[入るフレーム: 入る 1 つ前のフレームは床の近く](c-7-8-5-EntryVert-ja.md)）。もうフィールドではありません。部屋のフレームの歩きが入るフレームも追います。
  * `offSlow`: ラウンド 37 でなくなりました（項目 1-1-c-7-8-6、[`t0` のあとの空中の速さの上限: 遅いジャンプのフレーム](c-7-8-6-AirMove-ja.md)）。しきい値より下の空中での `X_Physics` と `ImposeFriction` の上限は ROM のチェック（`FrameModel.airOK`）から証明し、覚えている速さは遅い飛び上がりから追います（`slowAbs`、`absOr0`）。移動の終わりのあとの速さはそのままか 0 です（部屋のフレームの歩き `RoomSpeedKeep`）。残るのはフィールド `offCollide` です。`t0` のあとの遅いジャンプのフレームで、移動の終わりのあとの位置が高々 1 ピクセル動く（`CollideP`）こと。ラウンド 37 より前: `t0` のあとの空中の速さの上限。`t0` のあとのフレームでの水平のモデルによります。ラウンド 36 に測りました（`room-off-slow FM2 400`、下）。遅いジャンプで始まるどのフレームでも、プレイヤーのルーチンで `|v| ≤ A − 1` で覚えている速さ `s ≤ A − 1`。移動の終わりで `|v| ≤ A − 1`、`s` はプレイヤーのルーチンのものか `|v|` で、位置は `16·v` 動きます。フレームの残りは `FrameModel.Collide`（速さはそのままか 0、位置はそのままか 1 ピクセル戻るか、0 以下の速さからの 1 ピクセル前）。ただ `t0 − 1` からのこのフレームのうち 2,160 では、プレイヤーのルーチンで覚えている速さが `|v|` ではありません（当たったあと）。だからモデル `hstep`（`FrameModel.move_model`）はこれらを含みません。証明には次が要ります。覚えている速さがしきい値より下の空中での `X_Physics` の上限を、`FrameModel` の場合ごとの歩き（その `X_Physics` の歩きは覚えている速さを自由にしたまま）で通すこと。そしてこれらのフレームでの `Collide`。部屋の歩きはまだこれを与えません（移動のあと、画面の端の押さえと `ImpedePlayerMove` が位置を書きます）。1 フレームの一般の上限では足りません。最高速の 1 フレームは 2.5 px、そういう 12 フレームで 30 px（7,680）ですが、口はゴールの 22 px（5,632）先にしかありません。遅い上限は 18 px（4,608）です。
  * `offStand`: ラウンド 35 で証明しました（項目 1-1-c-7-8-3）。もうフィールドではありません。
* `Approach`、`Over`、`way` のどの場合か（項目 1-1-c-7-7、1-1-c-7-9、1-1-c-7-14）はそのままです。

**ファイル。** `Theorems/OffDrop.lean`（`nearB`、`offAt`、`slowF`、`slowArcs`、数 `above`、`allLayers`、道）。`Theorems/RoomJoin.lean`（`offNext`、`offB`、`standFam`、`pipeLands`、`pipeAOk`、`RoomRun.off_gap_of` とその補題、5 つのフィールド、`RoomCore.off_gap`）。`Main.lean`: `room-off-ways`。非公開の `Proof/RoomJoin.lean` に 8 つのチェック、`pipeA`、`pipeB`、`off_two`、`pipe_sum`、`stop_cap`、`hit_three` が入ります。ラウンド 35 で `pipeLands`、`pipeAOk`、`pipeA`、`pipeB`、`pipe_sum` とチェック `pipeAc`、`pipeBc` はなくなり、`landS` と `landC` がその代わりになり、チェック `keepA` と `offVfd` を足しました。 ラウンド 36 から `Main.lean` に `room-off-slow`（測っただけ）があり、`room-off-back` は `E + 1 < t0 + aboveF` の入りと `E = t0 − 1 + aboveS` の入りを数えます。
