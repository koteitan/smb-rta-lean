# 落ちるあいだの保存された速さ

ラウンド 33 から（[モデルに従うフレームのあとの保存された速さ](c-7-4-4-StoredClean-ja.md)）、[ボーナス部屋をつなぐ](c-5-RoomJoin-ja.md) のフィールド `ab_early` は 2 つの場合に求めていました。隠された向きのあとと、空中で左も右も押さずに古い保存された速さを持ち越したあとです。2 つ目の場合、フレーム `n` が読む保存された速さはフレーム `n − 1` が読んだものと同じです（`RoomRun.ab_stale`）。それをさかのぼると、落下の中の前の止まりに行きます。ラウンド 33 はそのようなフレームを 43 測りました。保存された速さは多くて 1 フレームに 0.375 px でした。ラウンド 34 からこの場合を証明します。ただし、それより前のフレームが、押している向きを隠されてプレイヤーのルーチンに来たときはのぞきます。

## 証明したこと

`ab(n)` はフレーム `n + 1` がプレイヤーのルーチンで読む保存された速さ（`read_ab`）、`A` は空中のしきい値（1 フレームに 1.5625 px）、`hs(n)` はフレーム `n` の終わりの水平の状態、`Φ` は `Potential` のポテンシャルです。

```
RoomRun.cap_fall :  d ≤ fall,  C + d ≤ t0  →  |v(C + d)| < A  ∧  (d < fall  ∧  st(C + d) = 0  →  Φ(hs(C + d)) ≤ stopPhi)
RoomRun.ab_fall  :  d ≤ fall,  C + d < t0,  (C, C + d] に向きを隠されたフレーム k がない  →  ab(C + d) < A
```

フレーム `k` が向きを隠される（`MaskedAt`）のは、保存された速さが `|v|` でプレイヤーのルーチンに来て、状態 `FrameModel.AtCtrl` でないときです。押している向きが当たりのビットで隠されています。

`cap_fall` は落下のフレームでの帰納法です。

* 最初の操作では止まっています（`start_fallR`）。
* 空中から `hstep` に従うフレームは空中の入力を持ち（`air_in_of`）、`AirCap.step_cap` が速さを `A` より下に保ちます。
* 落下の中で立って終わるフレームは `hstep` に従いません（`stand_off_of`。`C + fall` より前は床の上にいません、`fall_long_of`）。それで止まりで、`Φ ≤ stopPhi` です。
* そのような立ちからの `hstep` 1 フレームは多くて `gFast` しか増えず（`Potential.stepOk`）、`stopPhi + gFast + 255 < 256·A` です（新しい事実 `NumFacts.stop_cap`）。

`ab_fall` は同じフレームでの帰納法です。

* 最初の操作では保存された速さは 0 です（`StartAt.ab`）。
* モデルに従うフレームのあとでは `|v|` で（`ab_cleanW`）、`cap_fall` で `A` より下です。
* 状態 `AtCtrl` での止まりのあとでは、前の状態からの `hstep` の速さの大きさで（`ab_fresh`）、`cap_fall` と同じように `A` より下です。
* 古い止まりのあとでは多くて加える量 1 つと端数（`ab_stale`、`amax_air`）か、空中で左も右も押さないときは 1 つ前のフレームのものです。
* 向きを隠されたフレームだけはたどりません。

それで `RoomRun.ab_of_run` で、空中で左も右も押さない古い止まりのあと、保存された速さは `ab_fall` で `ab(n − 1) < A` です（フレーム `n − 1` は多くて `C + fall`: `hitF ≤ fall + 3`、新しい事実 `NumFacts.hit_three`）。ただし前のフレームに向きを隠されたものがあればのぞきます。

## フィールド

`ab_early`（1 フレーム）を変えました。

```
ラウンド 33 まで:  C + 34 ≤ n,  n + 1 < C + 37,  n < t0,  ¬CleanR(n),  ¬AtCtrl(T(n − 1)),  (T(n − 1) で xa = |v|  ∨  AirNoSide(n − 1))  →  ab(n) < A
ラウンド 34 から:  同じで  (T(n − 1) で xa = |v|  ∨  (AirNoSide(n − 1)  ∧  ∃ k, C < k < n,  MaskedAt(T(k − 1))))
```

前より弱くなりました。2 つ目の場合に前提を 1 つ多く求めます。なくなったフィールドも新しいフィールドもありません。新しいチェックは事実 `stop_cap`、`hit_three` です（数、`native_decide`）。

## 残ること（証明していない）

* 向きを隠されたあとの `ab_early` と `ab_run`（項目 1-1-c-7-4）。そのとき摩擦は速さをモデルと逆に押し、保存された速さをたどりません。
