# 出だしの最適性

**命題.** 1-1 の最初（止まっている）から、開けた平らな地面で、マリオが `n ≥ 32` フレームで右へ
進めるのは多くても `2.5·n − 41.94` ピクセル（32 フレーム以下では 38.06 ピクセル）。TAS の出だし
（fast accel の 32 フレームのあと右 + B）はちょうどその距離を進む。つまり、TAS の出だしより遠くへ
行ける入力はない。

1/256 ピクセル単位。`v_top` は走りの最高速。

```
状態     = (横の状態, 空中の残りフレーム, 距離)
1 ステップ: 地面では全部の入力（ジャンプの開始を含む）、空中ではジャンプの開始なし。
            横の状態は hstep、距離は 16·v' 増える
ジャンプ : 開始から着地のフレームまでの長さ ∈ [L_tap(|v|), L_hold(|v|)]
           （|v| は離陸のとき。エミュレータで測る: A を 1 フレーム押す、押し続ける）

opening  :  ∀ k ≤ 32、 Reach(start, k, u)  →  dist(u) ≤ 9744
            ∀ k、      Reach(start, 32 + k, u)  →  dist(u) ≤ 9744 + 16·v_top·k
            エミュレータで TAS の fast accel:  P(32) − P(0) = 9744
```

`9744 + 16·v_top·k = 16·v_top·(32 + k) − 10736` で、TAS の出だしのあと右 + B で走ると `P` は
ちょうどこれだけ動く（32 フレーム: `opening`、52 フレーム: [進める距離の上限](Reach-ja.md)）。

Lean: `Theorems/Opening.lean`（`optCheck`、`opt_of_check`、`opt_after`、`reach_le`。計算を使わずに
証明）、`Smbrta/Cert.lean`（`Reach`、`checkPrunedS`、`prunedS_spec`）、非公開の `opening`（探索を
`native_decide` で。約 4 秒）。

## しくみ

1-1 の最初から、上の状態をフレームごとにたどる探索。[進める距離の上限](Reach-ja.md) のポテンシャルの
上限で、もう 9744 を超えられない状態を捨てる: 距離 + `dbound(Φ, 残りフレーム)` ≤ 9744 のとき
（`reach_le`。`dist_le` から出る）。この上限が十分きついので、探索はプログラムとして約 1.4 秒で終わる。
残った状態は全部、距離が 9744 以下であることを確かめる。

9744 が限界になる理由（探索と TAS で見えること）:

* `X_Physics` が走りの最高速を許すのは、地面で右 + B（かダッシュのタイマー）のとき、または空中で
  1.5625 ピクセル／フレーム以上のときだけ。それ以外では、速さは歩きの最高速で止まる。
* 地面で 0.6875 ピクセル／フレーム未満のとき、進む向きと逆を押すと滑りが止まる（速さ 0）。なので遅いうちは、2 倍の
  加速の量（向き ≠ 進む向き）は空中でしか続けられない。
* ジャンプは少なくとも 21 フレーム続く。左右同時押しを 1 フレームしてから 2 フレーム目に跳ぶと、
  22 フレーム目の終わりに着地する。23 フレーム目の右 + B で歩きの最高速を超え、24 フレーム目の左で
  向きを直し、25 フレーム目に跳ぶと、2 倍の走りの加速の量で 32 フレーム目に最高速になる。

## 前提（Lean では証明していない）

* [進める距離の上限](Reach-ja.md) の開けた場所の上限の前提: `hstep` が 1 フレームの横の部分であること。
* 平らな開けた地面: ブロック、穴、壁がないので、空中にいるのはジャンプのあいだだけ。
* ジャンプの長さは、離陸のときの `|v|` だけで決まり、A を 1 フレーム押したときと押し続けたときの
  あいだにある（全部の速さで、押す長さ 1〜60 を確かめた: `smbrta jump-check`。A を離してから押し直しても、
  ジャンプの力は戻らない）。
* ジャンプには A を新しく押す必要があるが、モデルはそれなしでも許す（入力が増えるだけなので、上限は
  成り立つ）。Start と Select を押さないこと。

**ファイル.** `Theorems/Opening.lean`、非公開の `Proof/Opening.lean`。

**再現.**
```
.lake/build/bin/smbrta open-check 32 9744    # 探索をプログラムとして実行（true）
.lake/build/bin/smbrta open-check 32 9743    # 1 小さい値には届く（false）
.lake/build/bin/smbrta jump-check            # ジャンプの長さの前提
```
